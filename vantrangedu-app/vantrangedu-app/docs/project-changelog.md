# Project Changelog

## [2026-02-28] - Major Architecture Modernization

### Added
- **Next.js 15 Monorepo**: Restructured codebase into a scalable monorepo format utilizing Next.js 15 App Router and React Server Components.
- **Tailwind CSS v4**: Upgraded styling to the latest Tailwind CSS v4 engine for faster build times and optimized utility generation.
- **Cloudflare Edge Ecosystem**: Integrated Cloudflare D1 (Database), R2 (Storage), and KV (Caching Layer) for global edge performance.
- **DrizzleORM**: Adopted DrizzleORM for type-safe, lightweight database interactions.

### Changed
- Shifted away from legacy backend/database architecture to serverless, edge-native Cloudflare infrastructure.
